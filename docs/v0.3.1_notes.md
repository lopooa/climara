# v0.3.1 notes

This development step focuses on NCL-style panel, labelbar, and tickmark behavior.

## Panel

New or improved resources:

- `gsnPanelAutoTickLabels`
- `gsnPanelLeftLabelsOn`
- `gsnPanelRightLabelsOn`
- `gsnPanelBottomLabelsOn`
- `gsnPanelTopLabelsOn`
- `gsnPanelLabelBarSide`
- `gsnPanelLabelBarOrientation`
- `gsnPanelLabelBarWidthF`
- `gsnPanelLabelBarHeightF`
- `gsnPanelLabelBarOrthogonalPosF`
- `gsnPanelLabelBarParallelPosF`

The default panel behavior now hides interior tick/grid labels and keeps only the outer labels. This is closer to the practical NCL panel style and makes dense multi-panel maps cleaner.

## LabelBar

The shared panel labelbar can now be positioned relative to the full panel box. It supports bottom, top, left, and right side placement through `gsnPanelLabelBarSide`, while retaining explicit manual placement through `gsnPanelLabelBarLeft`, `gsnPanelLabelBarBottom`, `gsnPanelLabelBarWidth`, and `gsnPanelLabelBarHeight`.

## TickMark

Tick label controls are now more complete for all four sides:

- `tmXBLabelsOn`
- `tmXTLabelsOn`
- `tmYLLabelsOn`
- `tmYRLabelsOn`
- `tmXTLabelFontHeightF`
- `tmYRLabelFontHeightF`
- `tmXTLabelFontColor`
- `tmYRLabelFontColor`
- `tmLabelClipOn`

`tmLabelClipOn` is enabled by default to reduce tick-label overflow around panel edges.
