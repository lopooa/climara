
# v0.3.3 notes

This development step focuses on NCL-style MapPlot resources.

## Projection aliases

New or improved projection keys:

- `CylindricalEquidistant`
- `PlateCarree`
- `Robinson`
- `Mollweide`
- `Mercator`
- `Orthographic`
- `Stereographic`
- `LambertConformal`
- `AlbersEqualArea`
- `LambertAzimuthalEqualArea`
- `AzimuthalEquidistant`
- `TransverseMercator`
- `NearsidePerspective`
- `Geostationary`
- `InterruptedGoodeHomolosine`
- `EqualEarth`
- `Sinusoidal`
- `RotatedPole`

Some projections depend on the installed Cartopy version. Missing Cartopy projection classes are skipped in `list_supported_projections`.
