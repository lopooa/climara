# v0.3.2 notes

This development step focuses on advanced ContourPlot behavior while keeping the v0.3.1 path stable.

## Contour fill

New or improved resources:

- `cnFillMode = "Auto"`
- `cnFillMode = "Contourf"`
- `cnFillMode = "AreaFill"`
- `cnFillMode = "RasterFill"`
- `cnFillMode = "CellFill"`
- `cnFillFallbackMode`

`Auto` first tries a contour-style filled plot and can fall back to `pcolormesh` when contouring fails.

## Line labels

New or improved resources:

- `cnLineLabelsOn`
- `cnLineLabelInterval`
- `cnLineLabelFormat`
- `cnLineLabelFontHeightF`
- `cnLineLabelFontColor`
- `cnLineLabelInline`
- `cnLineLabelInlineSpacingF`

When `cnLineLabelsOn=True`, line contours are drawn automatically even if `cnLinesOn` is not explicitly enabled.

## Info label

New or improved resources:

- `cnInfoLabelOn`
- `cnInfoLabelString`
- `cnInfoLabelFontHeightF`
- `cnInfoLabelFontColor`
- `cnInfoLabelParallelPosF`
- `cnInfoLabelOrthogonalPosF`
- `cnInfoLabelJust`
- `cnInfoLabelBackgroundColor`
- `cnInfoLabelBackgroundAlphaF`
- `cnInfoLabelPerimOn`

The automatic info label reports min, max, and contour interval.

## Constant field

New or improved resources:

- `cnConstantFieldMode`
- `cnConstFLabelOn`
- `cnConstFLabelString`
- `cnConstFLabelFontHeightF`
- `cnConstFLabelBackgroundColor`

Constant fields no longer break the contour workflow. They are filled through a safe fallback path and can optionally display a constant-field label.
