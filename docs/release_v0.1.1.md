# climara v0.1.1

这是 climara 的一个早期小版本更新，主要用于整理 README、示例图、文档和 NCL-style plotting 的基础能力。

## 主要变化

- 更新 README 展示内容。
- 增加示例图片和 gallery 文档。
- 增加 NCL-style resource 查询函数。
- 增强 Panel / LabelBar / TickMark 示例。
- 增强 ContourPlot 示例。
- 增强 MapPlot 和投影示例。
- 增加 release 前检查脚本。
