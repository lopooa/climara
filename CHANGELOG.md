# Changelog

## v0.1.1

This is an early development update for climara.

### Added

- Added NCL-style resource summary helpers.
- Added projection alias summary helpers.
- Added gallery documentation.
- Added example figures under `docs/assets`.
- Added panel, contour, map, and projection examples.
- Added release check script.

### Improved

- Improved README for public GitHub display.
- Improved early NCL-style plotting documentation.
- Improved examples for Panel, LabelBar, TickMark, ContourPlot, and MapPlot.

### Notes

- This package is still experimental and under active development.
- APIs may change before a stable release.
